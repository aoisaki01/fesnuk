# Fesnuk

Full-stack social networking web application built with Next.js 15, React 19, TypeScript, and SQLite.

## Features

* User authentication with JWT and bcrypt password hashing
* Interactive feed with posts, media uploads, and comments
* Persistent data storage using `better-sqlite3`
* Client-side data fetching and revalidation with SWR
* Responsive layout built with Tailwind CSS and Heroicons

## Tech Stack

* Next.js 15 (Turbopack, App Router)
* React 19
* TypeScript
* SQLite via `better-sqlite3`
* Tailwind CSS v4
* SWR

## Getting Started

1. Install dependencies:

```bash
npm install
```

2. Run development server:

```bash
npm run dev
```

The application will start on `http://localhost:3000`.
